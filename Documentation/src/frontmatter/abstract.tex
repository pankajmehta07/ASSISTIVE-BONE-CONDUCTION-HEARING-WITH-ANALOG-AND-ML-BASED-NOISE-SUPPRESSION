This project proposes a real-time assistive hearing system that amplifies surrounding human speech and delivers it through a bone conduction transducer, keeping the user's ear canals open. Unlike conventional digital noise suppression pipelines that require expensive microcontrollers, this design uses an analog-first approach: active band-pass filters and a noise gate built from operational amplifiers remove steady background noise with near-zero latency. A lightweight machine learning model running on an STM32F401 microcontroller detects transient noises (e.g., door slams, footsteps) and momentarily reduces gain to prevent discomfort. The system is designed using a combination of analog and digital methodologies to implement a low-cost solution. Target applications include situational awareness for industrial workers, security personnel, and individuals with mild conductive hearing loss. The proposed system is expected to achieve higher STOI scores, noise reduction performance, lower latency and improved SNR.

\textit{\textbf{Keywords} : Bone conduction, analog noise suppression, lightweight ML, STM32, assistive hearing, low-latency audio}
